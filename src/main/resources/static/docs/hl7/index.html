FHIR/HL7 - Interoperabilidad de Datos Médicos

Descripción General​

El Proyecto FHIR/HL7 - Visor de Datos Médicos tiene como objetivo ofrecer un visor para consultar recursos FHIR (Fast Healthcare Interoperability Resources) relacionados con un sistema de salud. Los recursos son recuperados de un backend que gestiona la información clínica y administrativa de los pacientes, generando archivos JSON según los estándares HL7 (Health Level Seven). Este visor permite a los usuarios acceder a datos médicos de manera eficiente y conforme a los estándares internacionales de interoperabilidad.

HL7 y FHIR:
HL7 es un conjunto de estándares internacionales para el intercambio electrónico de información clínica y administrativa en sistemas de salud. FHIR es una implementación más reciente y moderna de estos estándares, diseñada para ser rápida y fácilmente integrable a través de servicios web y APIs. La implementación de FHIR en este proyecto permite una consulta eficiente y accesible a los recursos de salud digitalizados, tales como pacientes, médicos, informes de diagnóstico y observaciones.

Objetivos principales​

  • Proveer un visor de datos médicos basado en los estándares FHIR para consulta de recursos de salud.
  • Integrar el sistema de salud con la plataforma mediante APIs RESTful para la recuperación de recursos FHIR.
  • Garantizar el acceso seguro y eficiente a los datos médicos a través de una interfaz intuitiva.
  • Facilitar la gestión de recursos como pacientes, médicos, informes de diagnóstico, observaciones, entre otros.
  • Implementar una autenticación de usuarios basada en roles (administradores y médicos).

Funcionalidades principales​

  • Autenticación de usuario: mediante credenciales para acceder al visor de recursos FHIR.
  • Consulta de recursos FHIR: consultar todos los recursos de un tipo específico o consultar por UUID.
  • Formulario de consulta dinámico: permite a los usuarios elegir entre consultar todos los recursos o por UUID de un recurso específico.
  • Visualización de recursos: los resultados se muestran tanto en formato JSON como en un resumen legible para el usuario.
  • Backend de autenticación: gestión de login y validación de credenciales de usuarios (administrador y doctor).

Tecnologías utilizadas​

  • Frontend: HTML, JavaScript (para interacción y visualización de datos), CSS (diseño de la interfaz).
  • Framework: Nativo para el visor de recursos, adaptado a los estándares FHIR.
  • Backend: Spring Boot con REST API para manejar la autenticación y consulta de los recursos FHIR.
  • Base de datos: PostgreSQL para almacenar información sobre pacientes, médicos, diagnósticos, etc.
  • Dependencias clave:
    • HTTP: para las solicitudes a la API REST.
    • JSON: formato de intercambio de datos.

Vista general del flujo​

  1. Usuario inicia sesión mediante un formulario de login, enviando sus credenciales.
  2. Backend valida las credenciales y devuelve detalles del usuario autenticado (nombre, rol, ID público).
  3. Usuario es redirigido a la pantalla principal, donde puede consultar los recursos FHIR.
  4. Usuario elige el tipo de consulta (todos los recursos o por UUID) y realiza la consulta.
  5. Backend responde con los recursos solicitados, que se muestran en la interfaz del visor de datos.
info

Este proyecto está vinculado al backend de recursos FHIR, el cual gestiona los datos médicos y realiza las consultas de acuerdo con las necesidades de los usuarios.
